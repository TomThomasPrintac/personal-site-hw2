# Personal Website - CSS Homework 2

A one-page personal website built with HTML and CSS only, with a football-pitch design.

**Live site:** https://tomthomasprintac.github.io/personal-site-hw2/

## What's inside

- `index.html` - the page: hero, about, skills & hobbies, experience timeline, contact, footer
- `styles.css` - all styling, including a CSS grid, flexbox, animations and two media queries (900px and 600px) for tablets and phones
- `images/` - profile photo and SVG illustrations drawn for this site
- `תרגיל בית מספר 2 - הגשה.docx` - the submission document with the link to the live site
